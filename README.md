# ILNARA — A Cinematic Love Experience

Пять мгновений, созданных для Ильнары. Настоящее объёмное сердце из частиц, русские тексты, мягкий свет и переходы без прокрутки. Без музыки, фотографий, аналитики и внешних сервисов.

**Сайт:** https://reasqq.github.io/ilnara/

## Запуск

Нужен Node.js 24 LTS и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite, с окончанием `/ilnara/`.

```bash
npm run check
npm run build
npm run preview
```

`npm run build` сначала проверяет TypeScript, затем собирает полностью статический сайт в `dist`. Для воспроизводимой установки используйте `npm ci`; файл `package-lock.json` включён.

## Публикация на GitHub Pages

1. Загрузите проект в репозиторий `ilnara`, ветка `main`. Публикуйте содержимое этой папки, а не родительскую папку `outputs`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Сделайте push в `main` или запустите **Actions → Build, test and deploy ILNARA → Run workflow**.
4. Workflow выполнит `npm ci`, проверку TypeScript, сборку, браузерные тесты, загрузку `dist` и публикацию. Адрес будет доступен в окружении `github-pages`.

Workflow использует официальный `configure-pages`, чтобы автоматически подставить адрес сайта и путь репозитория в сборку. Никаких ручных переносов `dist` не требуется.

При переименовании репозитория Actions пересчитает адрес автоматически. Для локальной сборки скопируйте `.env.example` в `.env.local` и измените:

```dotenv
VITE_BASE_PATH=/new-repository/
VITE_SITE_URL=https://USERNAME.github.io/new-repository/
```

Для пользовательского домена `VITE_BASE_PATH=/`. `VITE_SITE_URL` должен быть полным HTTPS-адресом. Встроенный плагин Vite записывает абсолютные `og:url`, `og:image`, canonical и Twitter Card; в итоговом HTML нет шаблонных меток. Настройка `TEST_URL` позволяет запускать тесты по любому опубликованному URL.

Сайт доступен всем, у кого есть ссылка. `noindex` просит поисковики не индексировать романтическую историю, но не является ограничением доступа. При публикации в публичном репозитории исходники также публичны.

## Устройство проекта

- `src/experience/story.ts` — точные тексты и общее состояние композиции.
- `src/hooks/useSceneController.ts` — состояния enter / idle / exit; единый GSAP timeline для текста, камеры и частиц; блокировка повторного клика; аварийное завершение перехода.
- `src/experience/geometry.ts` — воспроизводимое облако объёмного сердца и пять целевых композиций.
- `ParticleHeart.ts` — интерполяция частиц и мягкое свечение в GPU-шейдере.
- `AmbientParticles.ts` — отдельный слой пространственной пыли и расфокуса.
- `ExperienceCanvas.tsx` — один renderer, камера, размеры, уровни качества, остановка при скрытии вкладки и освобождение ресурсов.
- `src/components` — текст, стеклянная кнопка, индикатор из пяти точек, экран загрузки.
- `src/styles/globals.css` — композиция для портретного, горизонтального и широкого экрана; безопасные зоны и `100dvh`.
- `public/og-cover.png` — оригинальная обложка 1200×630, снятая с работающей 3D-сцены.
- `public/heart-fallback.svg` — самостоятельная векторная россыпь частиц для устройств без WebGL.
- `tests/experience.spec.ts` — браузерная проверка истории и адаптации.

## Производительность и доступность

Одна WebGL-сцена, два объекта `Points`, два draw call на кадр. Частицы не создаются как отдельные Mesh; пять положений хранятся в буферах, а переходы вычисляет шейдер. Нет полноэкранного bloom и тяжёлых текстур.

| Качество | Частицы сердца | Фоновые частицы | Максимальный DPR |
|---|---:|---:|---:|
| High | 18 000 | 1 100 | 1,75 |
| Medium | 10 000 | 650 | 1,35 |
| Low | 4 500 | 300 | 1 |

На сенсорных устройствах стартует Medium; при низкой памяти или экономии трафика — Low. При устойчивой нехватке кадров качество снижается без пересоздания геометрии. Скрытая вкладка не рендерится. На повторе истории используются те же буферы и тот же canvas.

У `prefers-reduced-motion` короткие переходы и неподвижное облако. Кнопки семантические, доступны с клавиатуры, имеют focus-состояние и область касания не меньше 44 px. Масштабирование страницы не запрещено. При потере контекста, отсутствии WebGL или длительной загрузке автоматически включается векторная версия со всеми пятью сценами. На экране загрузки также можно выбрать её вручную.

Русская и латинская части Manrope размещаются в сборке. После загрузки HTML приложение не обращается к CDN, API, аналитике или шрифтам извне.

## Проверки

```bash
npx playwright install chromium
npm run build
npm test
```

Тесты запускают локальный просмотр production-сборки. Проверяют последовательность, повторные нажатия, три повторных прохождения, клавиатуру, отсутствие ошибок, рост памяти, потерю WebGL и резервный режим. Матрица размеров: 320×568, 360×800, 393×873, 412×915, 568×320, 800×360, 873×393, 1366×768, 1920×1080, 2560×1080.

Полный фактический отчёт и ограничения проверки — в `QA.md`.

## Обложка и резервная графика

`node scripts/create-fallback.mjs` воспроизводит резервную векторную графику из исходной формулы сердца. Для повторного снимка пяти сцен и обложки запустите dev-сервер на порту 5173 и `node scripts/capture.mjs`. Для пользовательского предпросмотра в мессенджере используется файл `og-cover.png`; сам опыт полностью процедурный. Мессенджеры могут кэшировать старую обложку.

Техническая документация: [публикация Vite](https://vite.dev/guide/static-deploy), [Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer), [GSAP timeline](https://gsap.com/docs/v3/GSAP/Timeline/).
