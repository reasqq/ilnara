# Проверка ILNARA

Дата: 18 ноября 2026 года.

## Выполнено локально

- `npm run check` — TypeScript без ошибок.
- `npm run build` — production-сборка успешно создана; все пути используют `/ilnara/`.
- `npm test` — 5 из 5 тестов успешно, 2,2 минуты, Chromium 159 / Playwright, Windows.
- Последовательное прохождение всех пяти сцен; три полных повтора без перезагрузки.
- Двойной вызов кнопки не пропускает сцены; нажатие на фон ничего не переключает.
- Клавиша Enter запускает переход; после входа фокус переводится к заголовку.
- После трёх повторов остаётся один canvas; прирост JavaScript heap после сборки мусора меньше 8 MiB.
- Нет ошибок JavaScript и сообщений console.error в обычном прохождении.
- При недоступности WebGL доступны все пять сцен и повтор с SVG-графикой.
- Принудительная потеря WebGL-контекста переключает приложение на SVG и сохраняет возможность продолжить.
- Reduced motion: сокращённые переходы; фон и частицы без постоянного движения.
- Прямой вход и обновление production-страницы работают.
- Заголовок страницы, абсолютный `og:image`, доступность обложки и отсутствие внешних сетевых запросов проверены автоматически.

## Адаптация

Проверены все пять сцен на каждом размере: 320×568, 360×800, 393×873, 412×915, 568×320, 800×360, 873×393, 1366×768, 1920×1080 и 2560×1080. Расширенный тест матрицы, включающий 568×320, отдельно повторно выполнен после финальных правок: 1 из 1 успешно, 55,4 секунды.

Тест проверяет размеры кнопок не меньше 44 px, положение текста и кнопок внутри экрана, свободное место над индикатором, отсутствие горизонтальной и вертикальной прокрутки. Размер окна меняется без перезагрузки, что дополнительно проверяет перерасчёт композиции.

Визуально просмотрены снимки всех пяти сцен при 393×873, финала при 1920×1080 и 800×360, обложки 1200×630. Исправлены слишком крупное сердце на desktop и смещение текста после перехода в горизонтальную ориентацию. Обложка создаётся из настоящей WebGL-сцены и использует текст «Для тебя, Ильнара».

## Производительность

- Два draw call, один canvas, геометрия переиспользуется.
- Максимум 18 000 частиц сердца и 1 100 частиц фона.
- Начальные уровни качества зависят от устройства; длительные кадры автоматически снижают качество.
- DPR ограничен до 1 / 1,35 / 1,75.
- Цикл рендеринга останавливается при `document.hidden`.
- Оценка Vite: JavaScript около 227,5 kB gzip, CSS около 6 kB gzip; используемые русская и латинская части шрифта — около 39,3 kB. Обложка не загружается самим приложением.

## Зависимости

`npm audit --omit=dev`: 0 уязвимостей runtime-зависимостей. Полный `npm audit` сообщает о 5 затронутых dev-пакетах из-за одной транзитивной проблемы ReDoS в `picomatch` (GHSA-fc5q-39xc-vjpf). Они используются только для локальной разработки и сборки; не входят в статический сайт. Доступная в реестре версия picomatch 4.0.7 всё ещё отмечена advisory. Принудительное понижение Vite до старой основной версии не применялось. Dev-сервер слушает только 127.0.0.1.

## Границы проверки

Это браузерная проверка с размерами мобильного экрана и сенсорным режимом, а не испытание на физическом Android-телефоне. Плавность 60 FPS на конкретной модели, поведение реальной адресной строки, вырезов экрана и встроенных браузеров мессенджеров не измерялись. Программный WebGL в тестах не является измерением производительности смартфона. Перед отправкой сюрприза полезно открыть итоговый сайт на целевом телефоне.

## Публикация

Workflow `.github/workflows/deploy.yml` повторяет сборку и браузерные тесты перед каждой публикацией. Фактический статус доступен на [странице GitHub Actions](https://github.com/reasqq/ilnara/actions). Ветка `main` публикуется в окружение `github-pages` по адресу https://reasqq.github.io/ilnara/.
